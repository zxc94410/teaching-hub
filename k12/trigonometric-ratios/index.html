第二章：三角比與海龍公式

什麼是海龍公式？

在傳統幾何中，要計算一個三角形的面積，我們通常需要知道它的底和高，即使用公式 $\text{面積} = \frac{1}{2} \times \text{底} \times \text{高}$。然而，當我們只知道三角形的三個邊長 $a$、$b$、$c$，而不知道任何高度或角度時，計算高就會變得非常繁瑣。

西元一世紀的亞歷山大港學者海龍（Heron of Alexandria）提出了一個巧妙的公式。只要知道三角形的三邊長，就能直接求出面積，這就是著名的海龍公式（Heron's Formula）：

$$\text{面積} = \Delta = \sqrt{s(s - a)(s - b)(s - c)}$$

其中，變數 $s$ 代表該三角形的半周長（semiperimeter），即周長的一半：

$$s = \frac{a + b + c}{2}$$
公式的優美之處

海龍公式將三角形的三邊長對稱地組織在一起。透過半周長 $s$，它考慮了三邊長與半周長的差值：$(s-a)$、$(s-b)$ 與 $(s-c)$。只要這三個差值都是正數（即滿足三角形兩邊之和大於第三邊的幾何不等式限制），公式內的根號底下就必然為正數，能夠完美計算出實數面積。

海龍公式的代數推導與證明

在高中階段，我們可以用餘弦定理（Law of Cosines）與基礎的三角恆等式來完成這個經典的幾何推導。

步驟 1
利用正弦值表示三角形面積

給定一個三角形，其邊長為 $a$、$b$、$c$，對應角為 $A$、$B$、$C$。我們知道，三角形的面積 $\Delta$ 可以透過包含夾角 $A$ 的公式表示為：

$$\Delta = \frac{1}{2} b c \sin A$$

為了方便後續代數處理，我們將兩邊平方，消去正弦的根號：

$$\Delta^2 = \frac{1}{4} b^2 c^2 \sin^2 A$$
步驟 2
利用餘弦定理與三角恆等式轉換

根據同角三角關係，我們知道 $\sin^2 A = 1 - \cos^2 A = (1 - \cos A)(1 + \cos A)$。

接下來，帶入餘弦定理中角 $A$ 的公式 $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$：

$$\sin^2 A = 1 - \left( \frac{b^2 + c^2 - a^2}{2bc} \right)^2$$

將這個結果帶回平方面積公式中：

$$\Delta^2 = \frac{1}{4} b^2 c^2 \left[ 1 - \left( \frac{b^2 + c^2 - a^2}{2bc} \right)^2 \right]$$
步驟 3
代數因式分解（平方差公式）

將括號外的 $b^2c^2$ 乘入中括號內，並且化簡分母 $4b^2c^2$：

$$\Delta^2 = \frac{1}{16} \left[ 4b^2c^2 - (b^2 + c^2 - a^2)^2 \right]$$

利用平方差公式 $X^2 - Y^2 = (X - Y)(X + Y)$，其中 $X = 2bc$，$Y = b^2+c^2-a^2$：

$$\Delta^2 = \frac{1}{16} \left[ 2bc - (b^2 + c^2 - a^2) \right] \left[ 2bc + (b^2 + c^2 - a^2) \right]$$
$$\Delta^2 = \frac{1}{16} \left[ a^2 - (b^2 - 2bc + c^2) \right] \left[ (b^2 + 2bc + c^2) - a^2 \right]$$

利用完全平方公式 $(b-c)^2$ 與 $(b+c)^2$ 進行二次重組：

$$\Delta^2 = \frac{1}{16} \left[ a^2 - (b - c)^2 \right] \left[ (b + c)^2 - a^2 \right]$$

再次對兩個中括號分別套用平方差公式：

$$\Delta^2 = \frac{1}{16} (a - b + c)(a + b - c)(b + c - a)(b + c + a)$$
步驟 4
帶入半周長 $s$ 簡化公式

定義半周長 $s = \frac{a+b+c}{2}$，則有全周長 $a+b+c = 2s$。據此我們可以重寫這四個括號：

$$\begin{aligned} b + c + a &= 2s \\ b + c - a &= (a + b + c) - 2a = 2s - 2a = 2(s-a) \\ a + c - b &= (a + b + c) - 2b = 2s - 2b = 2(s-b) \\ a + b - c &= (a + b + c) - 2c = 2s - 2c = 2(s-c) \end{aligned}$$

將上述四式代回 $\Delta^2$ 的式子中：

$$\Delta^2 = \frac{1}{16} \cdot 2(s-b) \cdot 2(s-c) \cdot 2(s-a) \cdot 2s$$
$$\Delta^2 = \frac{16}{16} \cdot s(s-a)(s-b)(s-c) = s(s-a)(s-b)(s-c)$$

兩邊開根號（取正值），即得到著名的海龍公式：

$$\Delta = \sqrt{s(s-a)(s-b)(s-c)}$$

Q.E.D. 證畢 ■
