1. 基礎三角比與圓投影

在直角三角形中，三角比通常定義為邊長的比值。然而，將三角比放入單位圓（Unit Circle）中，便能將其幾何意義轉化為「向量的坐標投影」。

給定一個半徑為 $r=1$ 的圓，從原點出發指向圓周上點 $P(x,y)$ 的向量與 $X$ 軸正向夾角為 $\theta$。點 $P$ 的坐標即為：

$$x = \cos\theta, \quad y = \sin\theta$$

而切線長度則對應正切值 $\tan\theta = \frac{y}{x}$。這啟發我們，每一個三角函數值都可以直接看作一條線段的投影長度。

2. 正弦定理與外接圓直徑

正弦定理（Law of Sines）指出：三角形各邊與其對角正弦值的比值相等，且等於該三角形外接圓的直徑 $2R$。

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

這代表當我們固定外接圓時，不論三角形的頂點在圓周上如何滑動，三邊長與對角正弦的比值始終鎖定在固定的直徑值 $2R$ 上。

圓周角定理與直角三角形投影

設三角形 $ABC$ 的外接圓半徑為 $R$。連接 $BO$ 並延長與圓周相交於 $A'$，使得 $BA' = 2R$ 為外接圓直徑。連接 $A'C$。

根據圓周角定理，在同弧 $BC$ 上，其圓周角大小相同，即： $$\angle BAC = \angle BA'C \implies \angle A = \angle A'$$

由於 $BA'$ 是直徑，所以直徑所對的圓周角 $\angle BCA' = 90^\circ$。在直角三角形 $\triangle A'CB$ 中： $$\sin A' = \frac{BC}{BA'} \implies \sin A = \frac{a}{2R} \implies \frac{a}{\sin A} = 2R$$

此法對其餘兩邊比值皆適用，得證正弦比值皆為直徑 $2R$。 ■

3. 餘弦定理與投影修正

餘弦定理（Law of Cosines）是畢氏定理在任意三角形中的推廣。它透過夾角的餘弦值，引入了一個幾何上的投影修正項。

$$a^2 = b^2 + c^2 - 2bc \cos A$$

當夾角 $A = 90^\circ$ 時，$\cos A = 0$，公式退化為畢氏定理 $a^2 = b^2 + c^2$。當 $A$ 為銳角或鈍角時，修正項 $-2bc \cos A$ 補償了非直角引起的偏差。

利用高與畢氏定理

在三角形 $\triangle ABC$ 中，自頂點 $A$ 向底邊 $BC$ 作一條垂線，交 $BC$ 於垂足 $H$，設高為 $h = AH$。

在直角三角形 $\triangle ABH$ 中，根據三角比投影定義： $$AH = c \sin B, \quad BH = c \cos B$$

垂足 $H$ 將底邊 $BC$ 切分為兩段。底邊長為 $BC = a$，另一段的長度為 $CH = |a - c \cos B|$。

在直角三角形 $\triangle ACH$ 中，套用畢氏定理： $$b^2 = AH^2 + CH^2$$ $$b^2 = (c \sin B)^2 + (a - c \cos B)^2$$ $$b^2 = c^2 \sin^2 B + a^2 - 2ac \cos B + c^2 \cos^2 B$$

利用恆等式 $\sin^2 B + \cos^2 B = 1$ 簡化式子： $$b^2 = a^2 + c^2 - 2ac \cos B \implies a^2 = b^2 + c^2 - 2bc \cos A$$ 同理移項可證對其餘邊長亦成立。 ■

4. 海龍公式與面積投影

海龍公式是解決「已知三邊求面積」的經典工具。它不需要求出任何高，只用三邊長對稱地算出面積。

$$\text{面積} = \Delta = \sqrt{s(s-a)(s-b)(s-c)}, \quad s = \frac{a+b+c}{2}$$

5. 中線定理與平行四邊形定理

中線定理（Apollonius's Theorem）與平行四邊形定理（Parallelogram Law）是三角形與平行四邊形中邊長平方和關係的幾何傑作，它們本質上互為雙生定理。

定理公式

中線定理（中線平方和關係）：在 $\triangle ABC$ 中，設 $D$ 為底邊 $BC$ 的中點，則：

$$AB^2 + AC^2 = 2(AD^2 + BD^2)$$

平行四邊形定理：平行四邊形中，對角線平方和等於四邊平方和之和：

$$d_1^2 + d_2^2 = 2(a^2 + b^2)$$

中線定理推導
利用餘弦定理與補角關係

在 $\triangle ABC$ 中，設 $D$ 為 $BC$ 的中點，即 $BD = CD$。設 $\angle ADB = \theta$，則其補角 $\angle ADC = 180^\circ - \theta$。

在 $\triangle ABD$ 中，依餘弦定理： $$AB^2 = AD^2 + BD^2 - 2(AD)(BD)\cos\theta \quad \text{--- (式 1)}$$

在 $\triangle ACD$ 中，依餘弦定理： $$AC^2 = AD^2 + CD^2 - 2(AD)(CD)\cos(180^\circ - \theta)$$

因為 $CD = BD$，且 $\cos(180^\circ - \theta) = -\cos\theta$，將其帶入整理得到： $$AC^2 = AD^2 + BD^2 + 2(AD)(BD)\cos\theta \quad \text{--- (式 2)}$$

將式 1 與式 2 直接相加，消去含有 $\cos\theta$ 的投影交叉項，即得： $$AB^2 + AC^2 = 2(AD^2 + BD^2)$$

Q.E.D. 證畢 ■
