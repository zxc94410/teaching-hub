自由堆疊幾何實驗室

歡迎來到三視圖探究中心！在左側 3D 空間中，點選「新增」或「刪除」，在網格地板上搭建方塊，並即時觀察上方 2D 投影面的輪廓變化。拖曳 3D 畫面即可自由旋轉！

課堂操作指南
  • 手動新增：點選綠色「新增」，按地面或積木的任何側面即可放置。
  • 方向參考：3D 網格邊緣設有彩色標示線與看板：藍色代表前、紫色代表右、金色代表上，對齊投影面超級輕鬆！
  • 自主鎖定視角：點選 3D 視窗右上角的 圖標，即可手動鎖定，挑戰大腦在無法旋轉時的空間投影感！

生活中的方向與視角

依據下方平面圖，回答方向情境題。記住：面向北方時，左邊是西、右邊是東；面向南方時方向相反！本章地圖不提供位置高亮標示，請自行看圖思考。

2D 數字與 3D 雙向連動

在台灣課本中，常使用「上視圖標示數字」代表該直列的積木層數。直接點選下方 2D 數字網格的 + 或 - 增減數值，積木就會拔地而起！

大師解題最大值秘訣

💡 前視圖高度：對齊上視圖的每一直行往前看，該直行中「最大數字的值」即為前視圖高度！

💡 右視圖高度：對齊上視圖的右側往左看，該橫列中「最大數字的值」即為右視圖高度！

空間幾何大冒險 使用說明

本互動講義是為了國中七年級「三視圖」單元所開發，提供流暢的 3D 與 2D 聯動機制，包含：

  1. 1. 自由堆疊積木：隨增隨減，即時獲得投影面圖。
  2. 2. 被擋住的正方體：開啟 ✨ 穿透看清完全藏在後方的「紅色」積木。
  3. 3. 生活中的方向與視角：小房子、玩具小車與水杯的多角度 silhouette 配對。
  4. 4. 用數字代替積木：體驗數字改變時 3D 積木隨即「拔地而起」的雙向聯動！
  5. 5. 依據三視圖找積木：逆向空間拼圖，考驗看圖搭建積木的空間還原力。
  6. 🏆 三視圖隨堂大挑戰：鎖定視角盲測，在 2D 畫布上點選答題。答完可點選「3D 轉向解析」，鏡頭會滑順旋轉，讓你秒懂！
